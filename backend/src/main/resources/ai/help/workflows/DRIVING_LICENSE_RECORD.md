Submit a driving license ("{myArea}" > "{drivingLicense}"): one license per person with several classes. Enter issue date, license number, issuing authority and the classes from the catalog (optionally expiry date and class dates) and upload a photo or scan. If a license is already on record, the approved request replaces it (card renewal). The recurring driving license check ("{fsk}") is a separate certification under "{certifications}".
